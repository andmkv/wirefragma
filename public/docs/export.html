The Markdown document

  1. Screen — mode, size, element and layer counts.
  2. ASCII Wireframe — an approximate character sketch of the layout.
  3. UI Elements — one compact section per visible element: type, label, bounds, parent, layer (when there are several), typography, list items and the LLM note. A Canvas adds its own sketch, one line per shape and the relationships between them; a Chart adds its data as a small Markdown table; a Drawing contributes its description.
  4. Spatial Summary — what sits where on the screen, and the reading order inside each container.
  5. Editable Project Source — the canonical JSON in a ui-project block, one element per line.
### `signInButton`

- Type: Button
- Label: Sign in
- Bounds: x=32, y=330, width=326, height=48
- Inside: `signInCard`

LLM note:
Validates the form, then navigates home.
The JSON is the source of truth. The ASCII sketch and the prose are advisory; import always rebuilds the wireframe from the ui-project block, so nothing is lost even if someone edits the text around it.

Exporting one layer

Layers → … → Export layer… exports only that layer's elements, optionally cropping the canvas to their content. Useful for asking a model about one form or one dialog.

Generating wireframes with a chat model

The WIREFRAGMA schema tab contains everything a model needs to produce a valid project: the document shape, the coordinate system, every element type, layers and nesting, a complete example and a JSON Schema. Paste it into a chat, describe the screen, and paste the answer into Import — a ui-project block, a json block or plain JSON all work.

Coding agents connected over MCP get the same schema from the get_wirefragma_schema tool, generated from the same source.

Whole projects: .wfproj

A .wfproj file holds a project with all its wireframes. Signed in, use a project's … menu → Export project (.wfproj). Any single wireframe can also be saved as a one-wireframe project: Export → Project JSON → Download .wfproj.

To bring it back, open Import:

  • Whole project (signed in) — the file becomes a new project with every wireframe, in order;
  • Wireframe — pick one wireframe from the file (this also works as a guest).

Import

  • Accepted: a Wirefragma Markdown export, raw project JSON, a .wfproj project file, or an LLM answer containing one of them.
  • As a guest, Import replaces the current document. Signed in, it creates a new wireframe in the project you choose.
  • Old documents (format version 1) are upgraded on import. Broken input shows an error and changes nothing.

Round trips

Export → import reproduces every project field: layers (including hidden ones), nesting, notes, typography, symbols, Canvas scenes and Drawing strokes.
