Getting started

Using the editor

One screen per wireframe, a fixed palette of generic primitives, layers, nesting and a note on every element.

The workspace

  • Toolbar — canvas preset (desktop 1200×800, mobile portrait 390×844, mobile landscape 844×390, custom), grid and snap, zoom, undo/redo, New, Layers, Import, Copy for LLM, Export.
  • Add — the element palette; new elements go into the active layer. Collapse it (panel button) to a compact two-column grid of icons.
  • Layers — layers and their elements as a tree: reorder by drag and drop, drop onto an element to nest, toggle visibility and lock.
  • Canvas — select, drag, resize, marquee-select.
  • Properties — name, label, LLM note, position and size, typography, symbol size, arrange controls.
  • Signed in, a Projects panel appears on the left (see Accounts).

Canvas and Drawing

Double-click a Canvas or Drawing, click the ✎ pencil that appears when you hover it, or use Edit canvas / Edit drawing in Properties. The popup edits a draft: Done applies everything as one undo step, × or Esc discards it.

  • Canvas — tools Select, Line, Arrow, Rectangle, Ellipse, Bezier and Text. Drag to draw, drag a shape to move it, drag its handles to reshape. Give shapes labels — they turn the diagram into a readable spec (“an arrow connects Login to User”). Bring forward / Send backward change the order; Delete removes the selected shape. An LLM description is optional.
  • Drawing — pen with three widths, an eraser that removes whole strokes, Undo/Redo, Clear. The export cannot read a sketch, so write an LLM description: without it the Drawing shows a ⚠ badge and is left out of the LLM export (it is still saved).

LLM notes

The note is where a wireframe carries intent. Good notes say what happens on click or tap, the states (empty, loading, error, disabled), where data comes from, validation rules and emphasis (primary, destructive). One to three sentences per element is plenty. Give every element a meaningful name such as emailInput or saveButton — names become the headings of the export.

Layers, order and nesting

  • The top of the Layers list is drawn in front and receives clicks first.
  • Use layers for big independent planes: page content, a modal, a popover.
  • Nesting: drop an element onto another in the Layers tree to put it inside. Children draw in front of their parent and move, hide, lock, copy and delete with it.
  • Hidden elements and layers are not drawn and are left out of the human-readable export (they stay in the project JSON). Locked elements cannot be selected on the canvas.
  • The … menu of a layer offers Export layer… — handy for explaining one form.

Selecting and moving

  • Click to select, Shift/⌘/Ctrl-click to add or remove, drag on empty canvas for a marquee.
  • A Container is grabbed by its border or its label; clicks inside its empty interior reach what is inside or behind it.
  • Each drag or resize is exactly one undo step.

Text and symbols

  • Text elements: font size 8–96, bold, italic, underline, left/center/right.
  • Icons, images, icon buttons and avatars accept emoji; the picker has categories and search. Symbol size is independent of the element size.

Languages, theme, saving

The interface speaks English, Russian, German, French, Spanish, Serbian, Japanese and Simplified Chinese, in a light, dark or system theme. The export always stays English. As a guest your project autosaves in this browser only — export anything you want to keep; signed in, every wireframe saves to your account.
